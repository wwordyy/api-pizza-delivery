# Pizza Delivery API

REST API для сервиса доставки пиццы и сопутствующих товаров: каталог, корзина, заказы, профиль, адреса, избранное, отзывы, админка (товары, категории, аналитика). Аутентификация по JWT.

**Стек:** Go, GORM, PostgreSQL; опционально SMTP (сброс пароля) и Cloudinary (загрузка изображений).

## Требования

- **Go** 1.25+ 
- **PostgreSQL** 14+ (или совместимая версия)

## Запуск локально

### 1. База данных

Создайте пустую базу в PostgeSQL


Имя должно совпадать с `DB_NAME` в конфиге (см. ниже).

### 2. Переменные окружения

В **корне репозитория** создайте файл `.env` (при запуске `go run ./cmd/api` из корня он подхватится автоматически). Минимально достаточно такого набора:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=ваш_пароль
DB_NAME=db_pizza_delivery
DB_SSLMODE=disable

JWT_SECRET=достаточно_длинная_случайная_строка
JWT_EXPIRES_HOURS=24

SERVER_PORT=8085
```

Если `.env` нет, приложение использует значения по умолчанию из кода (в т.ч. `DB_PASSWORD=1234`, `DB_NAME=db_pizza_delivery`) — удобно только для быстрого старта, в проде задавайте переменные явно.

**Опционально:**

- **SMTP** — `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`. Без них сброс пароля работает в упрощённом режиме (код может возвращаться в ответе при отсутствии почты).
- **Cloudinary** — `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`. Без них загрузка изображений в админке недоступна, остальной API работает.

### 3. Сборка и запуск

Из **корня репозитория**:

```bash
go mod download
go run ./cmd/api
```

При старте выполняется подключение к БД, **автомиграции GORM** и сиды справочных данных. В логах должно появиться сообщение о том, что сервер слушает порт (по умолчанию **8085**).


Остальные маршруты — в `internal/handler/router.go` (префикс `/api/...`).

## Структура проекта

- `cmd/api` — точка входа
- `internal/handler` — HTTP-хендлеры и маршруты
- `internal/service` — бизнес-логика
- `internal/repository` — работа с БД
- `internal/models` — модели GORM
- `internal/config` — загрузка конфигурации и `.env`
